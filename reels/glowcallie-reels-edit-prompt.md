# GlowCallie 릴스 자동 편집 명령어 (브랜드 맞춤판)

원본 "편집해줘" 명령어를 GlowCallie 톤(몸의 신호 · 회복 루틴 · 편안전활)에 맞게 바꾼 버전이에요.
사용법은 같아요. Claude 데스크톱 앱 → Code 탭 → 영문 폴더(예: `glowcallie_reels`) 선택 → 아래 박스 통째로 붙여넣기.

## 원본에서 바뀐 점

| 항목 | 원본 | GlowCallie 판 |
|---|---|---|
| 분위기 | 어두운 테크 (#110F18 + 앵버) | 밝은 세이지 (#EEF1EA + 모스·로즈·허니) |
| 강조 | 노란 자막 + 4~6초마다 팝 | 허니색 자막 + 8~10초마다 부드러운 강조 |
| 확대 | 강조 1.15배 | 최대 1.08배 (편도체 자극 줄이기) |
| 효과음 | 휙·팝·딩 | 물방울·종소리·부드러운 휙 |
| 장면 | 앱 연결·채팅·카운트업 | 몸 신호 체크·호흡 가이드·뇌 도식·루틴 카드·테스트 결과 |
| 구조 | 자유 | 4MAT(WHY→WHAT→HOW→WHAT IF)에 화면 구성 연결 |
| 용어 | - | "마음챙김" 자막 금지 → "알아차림" 자동 표기 |
| CTA | 댓글 → DM | 댓글 키워드 → 회복 루틴 테스트 링크 DM |

## 붙여넣을 명령어

```
너는 지금부터 GlowCallie 릴스 자동 편집 시스템을 만든다. 끝날 때까지 나에게 묻지 말고 진행해라.
필요한 프로그램은 네가 직접 설치해라(파이썬 3.11 이상, Node.js, ffmpeg 등). 설치 직후 명령어가 안 잡히면 설치된 전체 경로로 실행해라. 파이썬 패키지는 작업 폴더 안 .venv에 설치한다. 내가 직접 해야 하는 단계(비밀번호 입력 등)가 생기면, 컴퓨터를 잘 모르는 사람도 따라 할 수 있게 어디를 눌러서 무엇을 붙여넣는지 하나씩 알려줘. 나에게 하는 설명은 전부 쉬운 한국어로 해라.
지금 열려 있는 폴더를 작업 폴더로 쓰고, 모든 파일과 프로그램은 이 안에 만든다. 폴더 경로에 한글이 있으면 영문 이름 하위 폴더(예: reels_work)를 만들어 그 안에서 작업한다.

[0. 브랜드 정보]
- 계정: @glowcallie. 주제: 몸이 보내는 신호로 마음을 해석하고, 회복 루틴을 알려준다.
- 핵심 개념: "편안전활" = 편도체 안정 + 전전두엽 활성화. 화면에 처음 나올 때 한 번은 풀어서 보여준다.
- 용어 규칙: 자막·제목·그래픽에 "마음챙김"이라는 말을 쓰지 않는다. 내가 그렇게 말해도 자막 표기는 "알아차림"으로 바꾼다(말소리는 그대로 둔다).
- 시청자가 불안해지는 연출은 피한다. 빠른 깜빡임, 큰 흔들림, 날카로운 효과음, 빨간 경고 화면은 쓰지 않는다.

[1. 편집 규칙집]
작업 폴더에 "편집규칙집.md"(사람이 읽는 문서)와 "style.json"(숫자 버전)을 아래 규칙으로 만든다. 프로그램은 매번 style.json을 읽는다.
- 화면: 1080x1920 세로, 30fps
- 컷: 교정 대본에 있는 말만 남긴다. 문장 사이 멈춤은 최대 0.25초(차분한 호흡감), 남기는 단어 앞뒤로 0.05초 여유, 이어 붙인 곳은 10ms 크로스페이드, 0.12초보다 짧은 조각은 만들지 않는다.
- 단, 내가 "숨 들이쉬고", "내쉬고"처럼 호흡을 안내하는 구간은 멈춤을 줄이지 말고 그대로 둔다(호흡 가이드 장면과 맞춘다).
- 단어가 하나도 없는 0.6초 미만 조각(숨소리, 입소리, 코 들이키는 소리, 대본을 흘깃 보는 눈)은 버린다. 호흡 안내 구간의 숨소리는 남긴다.
- 같은 문장을 여러 번 읽었으면 마지막 테이크 중에서 카메라 보고 또렷하게 읽은 쪽(음량 큰 쪽)을 남긴다. 속삭이며 대본 보는 테이크는 쓰지 않는다.
- 구간마다 말소리 크기를 고르게 맞춘다(최대 +6dB 키우고 -3dB 줄임).
- 자막: Pretendard Bold(없으면 설치), 1080폭 기준 68px, 진한 먹색(#23291F) 글자 + 흰색 반투명 둥근 배경(불투명도 85%, 모서리 24px). 화면이 어두운 곳에서는 흰 글자 + 먹색 테두리 5px로 자동 전환. 한 줄 16자 이내, 2~4어절씩. 말과 정확히 맞춰 나타나고 바뀐다. 쉼표·마침표는 빼고 ?와 !는 남긴다.
- 강조 자막: 숫자, 몸 신호 단어(피곤, 두근, 뻐근, 무거움, 예민), 뇌 단어(편도체, 전전두엽, 편안전활, 알아차림), 행동 단어(바로, 딱, 1분, 3번), 댓글 키워드는 나올 때마다 허니색(#D6A542)으로 칠한다(키워드 글자만, 조사는 기본색). 그중 8~10초에 1번만 자막이 100→110→100%로 부드럽게 커지고, 물방울 효과음, 화면 1.08배 확대.
- 상단 훅 제목: 첫 문장에서 2줄(줄당 12자 안팎)을 뽑아 Noto Serif KR Bold 88px 먹색, 핵심 단어만 로즈색(#C97B86), 감정 이모지 1개(🌿 😮‍💨 💭 중). 첫 문장 동안만 보인다. 댓글 유도 문장이 시작되면 "댓글에 '키워드' 남기면 테스트 보내드려요" 제목으로 바뀐다. 제목은 얼굴을 크게 보여줄 때만 보이고, 위아래로 나눈 화면에서는 그래픽을 가리지 않게 숨긴다.

- 4MAT 화면 구성(필수): 교정 대본을 읽고 문장마다 WHY / WHAT / HOW / WHAT IF 중 하나로 표시한다.
  · WHY(공감·실패 경험): 얼굴 크게. 상단 훅 제목.
  · WHAT(핵심 메시지): 반전 문장("그런데 사실은…", "근데 여기서!")은 얼굴 크게 + 강조 1회. 나머지는 그래픽.
  · HOW(실행 방법): 전부 위쪽 그래픽 + 아래쪽 얼굴. 단계 번호를 크게 보여준다.
  · WHAT IF(변화 + 행동 유도): 전/후 비교 그래픽 후, 댓글 유도 첫 문장은 얼굴 크게.
  HOW가 없는 영상이면 편집은 끝까지 하되 보고할 때 "HOW 구간이 없어요"라고 알려준다.

- 모션그래픽(필수, 빠지면 실패): 영상의 65~80%를 위쪽 그래픽 + 아래쪽 얼굴로 나눈다. 장면은 문장 단위로, 말하는 내용을 그대로 그림으로 보여준다. HTML + GSAP으로 애니메이션을 만들고 브라우저(Playwright)로 프레임을 찍어 영상으로 만든다.
  디자인: 밝은 세이지 바탕(#EEF1EA, 부드러운 원형 그라데이션), 흰 카드(#FFFFFF, 모서리 28px, 은은한 그림자), 글자 먹색(#23291F)·보조글자(#5B6355). 강조색: 모스(#7C9473)=회복·좋음, 로즈(#C97B86)=긴장·신호, 허니(#D6A542)=핵심 숫자. 빨간색은 쓰지 않는다.
  움직임: 카드는 아래에서 천천히(0.6초, ease "power2.out") 올라오고, 숫자는 올라가고, 체크는 부드럽게 나타난다. 튀는 탄성(bounce·elastic)은 쓰지 않는다. 장면 시작 0.3초 안에 첫 요소가 보이게 하고, 글자와 카드는 폰에서 읽힐 만큼 크게(위쪽 칸을 꽉 채우게) 만든다.
  장면 템플릿(미리 만들어 둔다):
  ① 몸 신호 체크리스트(내 몸이 보내는 신호 3~5개에 체크)
  ② 호흡 가이드(원이 커졌다 작아지며 "들이쉬고 4 · 멈추고 · 내쉬고 6" 카운트, 내 말 속도에 맞춘다)
  ③ 뇌 도식(편도체 = 로즈 점이 진정되며 작아짐 → 전전두엽 = 모스색으로 밝아짐, "편안전활" 라벨)
  ④ 전/후 비교(❌ 지금 습관 vs ⭕ 회복 루틴, 두 카드)
  ⑤ 루틴 단계 카드(1·2·3 단계, 시간 표시 예: "1분")
  ⑥ 숫자 카운트업(예: "하루 3번", "90초")
  ⑦ 회복 타입 결과 카드(움직임 · 채움 · 쉼 · 연결 · 전환 중 하나)
  ⑧ 댓글 → DM 도착(댓글 키워드 입력 → "회복 루틴 테스트" 링크 메시지 도착)
  영상마다 네가 문장 내용을 읽고 맞는 템플릿과 문구를 직접 골라 넣는다. 모르는 숫자·연구 결과·주소는 지어내지 말고 가린다. 의학적 효과를 단정하는 문구(치료, 완치 등)는 자막·그래픽에 새로 만들어 넣지 않는다.

- 화면 확대: 얼굴 중심으로 컷마다 1.00→1.03 천천히, 강조 순간 1.08.
- 효과음: 장면·주제가 바뀔 때 부드러운 휙(작게), 강조에 물방울, 댓글 유도 제목에 맑은 종소리. 단어 0.05초 앞에, 효과음 사이 최소 2초. 효과음은 목소리보다 10dB 이상 작게. (저작권 없는 효과음을 직접 만들거나 받아서 쓴다.)
- 배경음: 잔잔한 앰비언트/로파이(피아노·패드 위주, 강한 드럼 없음), 목소리보다 약 20dB 아래, 말할 때 더 줄인다. 호흡 가이드 구간에서는 3dB 올린다. 처음 0.5초 페이드인, 마지막 1초 페이드아웃. 내가 bgm 폴더에 곡을 넣으면 그 곡을 쓴다.
- 인트로: 인사·로고 없이 첫 단어부터. 아웃트로: 마지막 말 0.5초 뒤, 마지막 0.5초 동안 "@glowcallie" 작은 글씨(먹색, 하단)를 띄우고 끝.
- 음량 -14 LUFS. 화질: 중간에 여러 번 다시 압축하지 말고 마지막에 한 번 고화질로 저장.

[2. 편집 프로그램 + 스킬]
위 규칙대로 편집하는 프로그램을 만들고, 내가 영상을 주고 "편집해줘"라고만 하면 실행되도록 스킬로 저장해라. (~/.claude/skills/glowcallie-reels-edit/SKILL.md, 같은 이름이 이미 있으면 덮어쓰지 말고 이름 뒤에 -2를 붙인다)
같이 "캡션도 써줘"라고 하면, 교정 대본을 바탕으로 인스타 캡션을 쓴다: WHY(실패 경험 공감) → WHAT(반전 1회) → HOW(번호 단계) → WHAT IF(변화 + 댓글 키워드 CTA). 문장 짧게, 줄바꿈 자주, ~해요 체, 이모지는 감정 포인트에만, "마음챙김" 대신 "알아차림". 해시태그 5개 이내.

[3. 편집 순서 — 반드시 이 순서]
① 원본 영상의 음성을 단어 단위 시간까지 전부 받아쓴다.
② 말을 더듬은 곳, 같은 말을 다시 한 곳, 길게 멈춘 곳(호흡 안내 구간 제외)을 뺀 "교정 대본"을 만든다. 할 수 있는 건 지우기뿐이다. 내 말의 내용과 말투는 절대 바꾸지 않는다. 잘못 들린 단어는 자막 표기만 고친다(편도체, 전전두엽, 편안전활, 글로우캘리 등). 교정 대본은 네가 받아쓰기 표(단어 번호·시간·음량)를 직접 읽고 "지울 단어 번호", "문장별 4MAT 표시", "문장별 화면 구성(그래픽 장면)" 파일로 작성하고, 프로그램은 그 파일대로 편집한다.
③ 교정 대본에 있는 말만 남기고 컷 편집한다.
④ 자막, 강조 자막, 상단 제목, 모션그래픽, 효과음, 배경음을 규칙집대로 넣는다.
⑤ 완성 파일을 mp4로 저장하고, 첫 화면(훅 제목이 보이는 프레임)을 cover.jpg로 따로 저장한다.

[4. 스스로 검수]
완성본을 다시 받아써서 자막과 비교해 오타를 고친다. "마음챙김"이 자막·그래픽에 남아 있으면 고친다. 소리가 끊기는 곳(경계 클릭음, 단어 끝 잘림, 말 중간 긴 무음), 화면이 멈추거나 검게 나오는 곳을 찾아 고친다. 마지막으로 완성본에서 프레임 모아보기를 뽑아 직접 보고, 자막이 얼굴·제목·그래픽을 가리지 않는지, 모션그래픽이 65% 이상인지, 4MAT 네 구간이 다 있는지 확인한 다음 짧게 보고한다(원본 → 완성 길이, 지운 말 개수, 4MAT 구간별 시간, 고친 것).

[5. 피드백 반영]
내가 결과를 보고 아쉬운 점을 말하면(예: "자막이 작아", "배경음이 커", "너무 차분해") 그 내용을 규칙집과 style.json에 추가하고, 규칙집 맨 아래 "피드백 기록" 표에 남겨서 다음 편집부터 자동으로 반영한다.

[6. 완성 확인]
다 만들면 작업 폴더에 있는 영상으로 한 번 편집해 보고 "편집 시스템 완성"이라고 말해라. 영상이 없으면 "10초짜리 영상 하나를 찍어서 이 폴더에 넣어 주세요"라고 한 줄로 알려주고 기다려라.

[경험상 주의]
- 폴더 경로에 한글이 있으면 일부 도구가 파일을 못 연다. 작업 파일은 영문 폴더에서 처리한다.
- 받아쓰기는 faster-whisper(large-v3-turbo, 단어 단위 시간 켜기)를 쓴다. 단어 시작 시각이 앞쪽 무음까지 먹는 경우가 많으니, 소리 크기로 실제 말소리 구간을 다시 잡아서 자른다. 받아쓰기 힌트 단어로 "편도체, 전전두엽, 편안전활, 알아차림, 글로우캘리, 회복 루틴"을 넣는다.
- 얼굴 위치 찾기·그래픽 렌더용 브라우저처럼 추가로 받아야 하는 파일이 있으면 네가 알아서 받는다.
```
