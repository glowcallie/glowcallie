# 릴스 편집 가이드

릴스를 만들거나 편집할 때 기본으로 적용하는 기준이에요.
처음 적용한 영상: 「48살, 머리숱 부자의 관리법」 (2026-11-12, 노션 7-zip 페이지 내용)

## 1. 첫 3초 후킹
- 첫 화면에 제목을 크고 눈에 띄게 넣기 (예: 「48살, 머리숱 부자의 관리법」)
- 제목은 가벼운 팝업 애니메이션으로 등장
- 핵심 결과물(예: 풍성한 머릿결)이 잘 보이도록 살짝 줌인

## 2. 화면 변화와 영상 효과
- 같은 구도가 이어지면 줌인 · 줌아웃 · 클로즈업으로 변화 주기
- 주요 장면(예: 두피 진단, EMS, 앰플 관리)은 디테일이 보이게 강조
- 비슷한 장면이 반복되면 더 빠르게 편집
- 음악 비트에 맞춰 컷 전환

## 3. 자막과 애니메이션
- STEP 1, 2, 3 단계 자막에 가벼운 등장 애니메이션
- 핵심 키워드는 크기나 굵기로 강조
- 정보성 자막은 경험담 말투로
  - 예: 「40대부터는 모발뿐 아니라 두피 상태도 중요하더라고요.」

## 4. 마지막 장면
- 마지막 결과 장면(예: 풍성한 머릿결)을 더 강조
- 마무리 자막은 다짐형으로
  - 예: 「머리숱 부자, 오래오래 유지해 볼게요! ♡」

## 5. 전체 톤
- 자연스러운 분위기는 유지하고, 더 감각적이고 생동감 있게 다듬기
- ❌ 화려한 전환 효과, 과한 애니메이션
- ⭕ 자연스럽고 세련된 느낌
- 2~3초마다 구도나 자막에 작은 변화
- 첫 3초는 시선을 확 끌고, 중간은 리듬감으로 지루하지 않게
