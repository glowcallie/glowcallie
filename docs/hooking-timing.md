# 후킹 타이밍 정리 (원문 참고자료)

출처: PD 으상 — 시선 붙잡는 후킹 타이밍 팁

## [비교 후킹 타이밍]

영상 **앞단**에 배치. 극과 극, 시작과 끝 등 극적인 변화를 짧은 시간에 보여줘 시각·텍스트 후킹을 동시에 일으킨다.

### 1. "아직도 이렇게 하세요? 망하는 지름길 vs 성공 비결" 🚫
정답을 즉각적으로 보여주는 방법.
- '조회수 안 나오는 영상' vs '떡상하는 영상' 편집법 비교
- '팔로워 도망가는 프로필' vs '팔로우 누르게 되는 프로필' 비교
- '촌스러운 폰트' vs '요즘 유행하는 감성 폰트' 비교

### 2. "다이소 꿀템, 100만 원짜리보다 나은 이유" 💰
가성비·성능 차이를 극명하게 보여줄 때.
- '1,000원짜리 조명' vs '10만 원짜리 조명' 촬영 결과물 비교
- '유료 편집 앱' vs '0원 편집 앱' 결과물 비교
- '브랜드 티셔츠' vs '보급형 티셔츠' 세탁 후 핏 비교

### 3. "포토샵 필요 없음! 사진 찍는 법 하나로 인생샷 건지기" 📸
기술의 중요성을 단번에 느끼게.
- '일반인이 찍은 사진' vs '작가가 찍은 사진' 구도 비교
- '기본 카메라' vs '보정 어플' 색감 차이 비교
- '서서 찍기' vs '앉아서 찍기' 다리 길이 차이 비교

## [분산 후킹 타이밍]

어디에 들어가도 괜찮지만 주로 **영상 시작** 후킹, 또는 메인 후킹이 끝난 뒤 서브 후킹으로 **영상 중간**에 배치.

### 4. "눈이 쉴 틈이 없네! 1초 만에 시선 강탈하는 법" 👀
화면을 꽉 채워 반복 시청 유도.
- 메인 영상 옆에 실시간으로 올라가는 '수익 인증' 숫자
- 인터뷰 영상 밑에 '핵심 요약 자막' + '진행률 바'
- 요리 영상 배경에 'ASMR 소리 파형' + '레시피 메모'

### 5. "정보량이 폭발한다! 저장 안 하면 손해 보는 영상" 💾
정보가 많아 보이게 만들어 '저장' 유도.
- 화면 4분할로 다른 각도의 촬영 현장 동시 노출
- 배경은 브이로그, 앞쪽엔 '추천 앱 리스트' 텍스트 빠르게 흐르게
- 제품 리뷰 중 구석에 '실제 구매 후기' 팝업 계속 띄우기

### 6. "감성 한 스푼에 전문성 두 스푼! 세련된 영상의 비밀" 🎬
단순한 영상도 퀄리티 높게.
- 풍경 영상 중앙에 '일기 형태의 긴 글' + '기온/날씨' 아이콘
- 코딩/공부 영상 옆에 '타이머' + '읽는 책 제목'
- 운동 영상 위에 '소모 칼로리' + '심박수' 그래픽

## [보상 지연 후킹]

심리학 기반. 영상 시작과 동시에 시청자가 **무얼 보고 싶어할지 정해주는** 후킹.
결과물을 먼저 보여주고 과정을 천천히 밟거나, 결과가 기대되는 시작을 맨 처음에 보여준다.

### 7. "절대 공개 안 하려던 제 영업비밀, 딱 오늘만 풉니다" 🔓
기대감 최고조.
- 비밀 사이트 공개 전 "준비되셨나요?" 자막 + 심호흡 장면
- 떡상 키워드 공개 전 컴퓨터 켜고 로그인하는 과정 천천히
- 노하우 직전 "이거 알면 진짜 놀라실 텐데..." 뜸 들이기

### 8. "결과가 궁금해서 못 나갈걸요? 끝까지 보게 만드는 마법" ✨
가장 중요한 순간 앞에 다른 행동 삽입.
- 맛집 공개 직전 "저장부터 하세요!" + 저장 버튼 누르는 장면
- 비포애프터 공개 직전 거울·렌즈 닦는 장면
- 꿀팁 1·2번 먼저, 3번은 '청소 영상' 뒤에 배치

### 9. "이 영상의 반전은 5초 뒤에 시작됩니다" 🤫
시청 지속 시간 극대화.
- 메이크업 완성 샷 전 화장품 뚜껑 여는 소리만 길게
- 다이어트 성공 사진 전 운동화 끈 묶는 장면 길게
- 돈 버는 법 직전 여유롭게 커피 타는 모습 먼저
